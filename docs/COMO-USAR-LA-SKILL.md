# Cómo pedir una presentación nueva con la skill `presentacion-educativa`

La skill vive en `.claude/skills/presentacion-educativa/` de este repo y, si la guardaste en tu
perfil de claude.ai, en todas tus sesiones de Claude Code.

## Qué decir

Abre una sesión de Claude Code (en este repo o en otro cualquiera), adjunta el material y
escribe algo así:

> Usa la skill presentacion-educativa. Título: «…». Público: … (alumnado de instituto /
> funcionarios / universidad). Material adjunto: … Quiero la presentación interactiva
> [y la propuesta en PDF para el Ayuntamiento de …]. Duración aproximada: … minutos.
> Autor que debe figurar: …

No hace falta invocarla por nombre: con decir «presentación interactiva para alumnos»,
«píldora formativa», «propuesta para el ayuntamiento» o nombrar a Víctor ya se activa.

## Qué adjuntar

Vale cualquier combinación de pptx, PDF, docx, imágenes o notas por mensaje. Cuanto más
contexto, mejor: para quién es, cuánto dura, en qué municipio, qué tono, qué no incluir.

## Qué recibirás

- Enlace de la presentación (artefacto, se abre en el móvil) y zip para usar sin internet.
- Si la pides, la propuesta en PDF con marcadores amarillos para lo que no se sabe (precios,
  nombres, fechas).
- Guía del ponente si hay un ponente distinto de ti.
- Un informe con los textos que se han redactado nuevos, las decisiones a validar y los
  marcadores pendientes.

## Para ahorrar uso

Pide que el relleno de contenido lo hagan agentes con un modelo más barato («ejecútalo con
Opus y revisa tú») como hicimos aquí: la skill ya contempla ese reparto.

## Proyectos hechos con ella

- `presentacion/` + `propuesta/`: «Nadie nace sabiendo cuidar» (7 unidades, La Laguna).
- `formacion-logistica-animales/`: píldora para ayuntamientos y universidad (4 unidades).
